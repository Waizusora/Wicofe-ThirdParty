# Third-Party Documentation Index

This directory documents external components integrated or proposed for Wicofe.

## Scope
- Component inventory and exact upstream provenance.
- Versions, commits, source integrity, and download records.
- License texts, notices, attribution, and redistribution obligations.
- Local patch tracking, security advisories, and maintenance status.
- Dependency and enabled-feature audits.

## Ownership
This repository owns compliance/provenance records and third-party intake policy. [Wicofe-Ports](https://github.com/Waizusora/Wicofe-Ports) owns build recipes and integration patches. Component repositories own their use of dependencies and must link to the corresponding third-party record.

## Approval
A successful build or an OSI-approved license alone is not sufficient approval. Review exact versions, transitive dependencies, optional features, generated code, and redistribution obligations. Third-party code retains upstream licensing.
